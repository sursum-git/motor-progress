Documentação e execução

Escolha uma consulta em POST /api/query.php, clique em Try it out, selecione o exemplo, informe os filtros no JSON e clique em Execute. O retorno aparece em Server response.

Paginação: informe page (1 a 1.000.000) e pageSize (1 a 1.000) na raiz do JSON. Enquanto hasMore for verdadeiro, avance page, mantendo os filtros e o tamanho. O limite vale para toda a API externa, incluindo Postman e integrações.

Para retornar todos os registros filtrados em uma resposta, use "paginate": false. Nesse modo, page e pageSize não controlam o resultado; hasMore retorna falso e pageSize retorna nulo. Permanecem os limites de tempo e tamanho da resposta do serviço.

Cursor: escolha um exemplo “cursor” e envie "paginationMode": "cursor", pageSize e os filtros, sem page ou paginate. Na próxima chamada, copie nextCursor para cursor, mantendo consulta, filtros e tamanho. Termine quando hasMore for falso. O cursor vence em 15 minutos; após vencer, reinicie a navegação. O modo exige chave única e não oferece uma fotografia dos dados durante alterações.

No Postman, a pasta Consultas por cursor salva automaticamente a continuação em uma variável por consulta. Execute novamente a mesma requisição para avançar. Ao terminar ou mudar filtros/consumidor, limpe essa variável para reiniciar. Consultas com agregação ou distinct continuam usando os modos por página ou sem paginação.

Assíncrono: selecione o exemplo com sufixo async e envie "execution": "async", sem cursor. O HTTP 202 devolve jobId. Informe esse valor no GET /api/jobs.php até o estado completed; depois execute o GET /api/job-result.php para obter o JSON. Ambos exigem o token do mesmo consumidor e sua permissão atual. No Postman, a pasta Consultas assincronas guarda o job_id automaticamente. O worker é acionado a cada minuto; o job processa a página solicitada, ou o conjunto completo com paginate:false. Limites: cinco jobs pendentes por consumidor, resultado de até 64 MiB, disponível por 24 horas desde o envio.

Autenticar consumidor

Use a credencial gerada na página de tokens. O acesso continua limitado às consultas autorizadas. O token dura 15 minutos; esta tela o renova enquanto estiver aberta.

Também é possível informar um token já emitido no botão Authorize, sem o prefixo Bearer. As credenciais ficam apenas na memória desta página e são limpas ao sair ou recarregar.
